# 校园生活服务微信小程序

一款面向校园场景的多功能微信小程序。项目当前以食堂点评为核心入口，并逐步扩展失物招领、校园服务、AI 助手、个人中心和管理端能力。

## 当前功能

- 食堂与窗口浏览
- 多维度评分与评价发布
- 动态评价流
- 窗口榜单与标签聚合
- 失物招领模块
- 个人中心与校园资产入口
- 自定义 tabbar 与统一图标体系
- 云函数封装：登录、评价统计、榜单、标签、内容/图片安全、管理员校验、失物招领
- 服务层封装：用户、评价、窗口/食堂、AI、失物招领、存储

## 目录结构

```text
cloudfunctions/      云函数
components/          公共组件
config/              学校、主题、AI 等配置
custom-tab-bar/      自定义底部导航栏
images/              图片与图标素材
models/              数据模型
pages/               小程序页面
scripts/             图标生成等辅助脚本
services/            业务服务封装
utils/               通用工具方法
```

## 本地开发

1. 使用微信开发者工具导入项目根目录。
2. 确认 `project.config.json` 中的小程序 AppID 与云环境配置。
3. 在微信开发者工具中开通并绑定云开发环境。
4. 分别上传并部署 `cloudfunctions/` 下的云函数。

## 注意事项

- `project.private.config.json` 已被 `.gitignore` 忽略，不应提交到仓库。
- 云函数依赖需要在微信开发者工具中安装或上传部署时处理。
- 当前项目仍处于迭代阶段，部分入口为占位功能，后续会继续完善校园问答、反馈工单、活动、二手交易与积分体系。
